# 🤥 الكذّاب بيننا — The Liar Among Us

لعبة جلسات للأصدقاء والعائلة (3 إلى 10 لاعبين). **جوال واحد يتنقل بين اللاعبين.**
واحد منكم لا يعرف الكلمة السرية، وعليكم كشفه قبل أن يخدعكم!

> النسخة القديمة من المشروع («دفتر الظل») محفوظة في الوسم `shadow-ledger-v1-archive`.

## طريقة اللعب
1. كل لاعب يضغط مطولاً على بطاقته ليعرف دوره سراً: الكلمة، أو أنه **الكذّاب**.
2. تناقشوا وتلمّحوا للكلمة دون ذكرها. الكذّاب يتظاهر بأنه يعرفها.
3. صوّتوا على من تظنونه الكذّاب. إذا انكشف يحصل على فرصة أخيرة لتخمين الكلمة.
4. **بطاقات الفوضى** تقلب بعض الجولات: كذّابان، كلمة مموّهة، جولة سريعة، جولة همس، أو جولة بلا كذّاب!
5. **المذيع الساخر** يعلّق على اللاعبين (اختياري بصوت الجهاز).

### النقاط
| الحالة | النقاط |
|---|---|
| الكذّاب ينجو | +3 (أو +2 لكل كذّاب عند وجود اثنين) |
| الكذّاب ينكشف ويفشل في التخمين | +1 لكل صادق |
| الكذّاب ينكشف لكنه يخمّن الكلمة | +2 للكذّاب |
| جولة بلا كذّاب وقرر الجميع «لا كذّاب» | +2 للجميع |
| اتهام بريء في جولة بلا كذّاب | −1 للمتهم |

## التقنية
- React 19 + TypeScript + Vite، ومغلّف للجوال بـ Capacitor (iOS / Android).
- يعمل دون إنترنت، بلا إعلانات أو تتبع أو أذونات.
- `src/game/engine.ts`: منطق الجولات والنقاط · `src/game/words.ts`: الكلمات والفئات · `src/game/host.ts`: المذيع.

## التشغيل
```bash
npm install
npm run dev          # تطوير محلي
npm run build        # فحص الأنواع + بناء الإنتاج
npm run cap:sync     # مزامنة مع iOS/Android
```
